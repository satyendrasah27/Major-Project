# PolitiView India — Political Issue Detail

Responsive issue-detail page recreation based on the supplied Bihar voter-roll revision reference.

## Run locally
1. Extract the ZIP.
2. Open `index.html`, or run:
   ```bash
   python3 -m http.server 8000
   ```
3. Visit `http://localhost:8000`.

## Included
- PolitiView sidebar and global search
- Issue title, breadcrumbs, metadata, priority, hero image and overview button
- Quick Summary, Detailed Context, and Deep Dive modes
- Overview, Timeline, Impact, Perspectives, Sources and Related Issues tabs
- Importance score visualization, explanation and Quick Facts
- Related issue cards
- Save and Share demo controls
- Responsive desktop, tablet and mobile layout

## Prototype limitations
Issue text and importance scores are example UI content, not live verified reporting or live AI analysis. Video playback, real source links, bookmarks, and backend persistence are not connected. Hero images load from Unsplash and need an internet connection. For production, integrate trusted official Election Commission sources and verified reporting.
