# PolitiView India Landing Page

Responsive HTML/CSS/JavaScript landing page recreation based on the supplied reference screenshot.

## Run locally
1. Extract this ZIP.
2. Open `index.html` in a browser, or run:
   ```bash
   python3 -m http.server 8000
   ```
3. Visit `http://localhost:8000`.

## Included
- Hero section with product dashboard mockup
- Sticky navigation and mobile menu
- How it works section
- India-focused geographic hierarchy
- Multiple perspectives section
- 2-minute, 10-minute and 1-hour learning modes
- CTA and onboarding modal with all 28 Indian states and 8 union territories
- Responsive styles for desktop, tablet and mobile

## Prototype notes
- Search, login, onboarding, product demo, and perspective lens are UI demonstrations; no account or backend is connected.
- Headlines shown inside the mockup are sample content and must not be treated as verified live reporting.
- Photos load from Unsplash and require internet access.
- The India map in the geography section is an illustrative shape, not an accurate political boundary map.
- For production, connect authentication, verified Indian news/government sources, a real map, and backend APIs.
